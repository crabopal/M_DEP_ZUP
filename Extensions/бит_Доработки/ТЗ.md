# Техническое задание. Награды, дисциплинарные взыскания, штрафы ПДД

Все изменения ведутся в расширении `бит_Доработки`. Основную конфигурацию и расширение `ЮЦАУ` не менять. Префикс расширения `бит_`.

Объекты метаданных создаёт человек. Агент их не создаёт. Если объекта нет, остановиться и перечислить, чего не хватает. Новые подсистемы не создавать. Заимствованные подсистемы: `юцТабельщик` (добавлены регистр и отчёт `бит_ШтрафыПДД`), `Кадры.ДисциплинарныеВзыскания` вместе с родительской `Кадры` (в состав включён отчёт `бит_ДисциплинарныеВзысканияСотрудников`) и `ПодключаемыеОтчетыИОбработки` (тот же отчёт подключён к панели отчётов).

`РегистрСведений.НаградыФизическихЛиц` и справочник `Награды` не изменять: клиент уже ведёт в них местные награды. Зарплату и табель не менять. Штрафы по зарплате не проводить. Ограничения по подразделению нет.

## Объекты, которые создаёт человек

Модули и схемы компоновки оставить пустыми. Новые объекты в роль `бит_ОсновнаяРоль` не включать.

### Справочник

`бит_ВидыВзысканий`, синоним «Виды взысканий». Неиерархический. Длина наименования 100. Предопределённые элементы: `Замечание`, `Выговор`. Дополнительные реквизиты не добавлять.

### Регистры сведений

Собственные объекты расширения, независимые, непериодические. У каждого стандартные формы списка и записи. Измерение `НомерПоПорядку` — служебный ключ строки, на формах его не показывать.

`бит_ВзысканияСотрудников`, синоним «Дисциплинарные взыскания».

| | Имя | Тип |
|---|---|---|
| Измерение | `Сотрудник` | `СправочникСсылка.Сотрудники`, ведущее, запрет незаполненных |
| Измерение | `НомерПоПорядку` | Число 5, неотрицательное |
| Ресурс | `ВидВзыскания` | `СправочникСсылка.бит_ВидыВзысканий`, запрет незаполненных |
| Ресурс | `Дата` | Дата |
| Ресурс | `НомерПриказа` | Строка 30 |
| Ресурс | `ДатаПриказа` | Дата |
| Ресурс | `Комментарий` | Строка 500 |

`бит_ШтрафыПДД`, синоним «Штрафы ПДД». Те же два измерения.

| Ресурс | Тип |
|---|---|
| `Дата` | Дата, запрет незаполненных |
| `ПунктПДД` | Строка 20 |
| `Нарушение` | Строка 250 |
| `Сумма` | Число 15.2, неотрицательное |

### Отчёты

Схему компоновки оставить пустой.

- `бит_ДисциплинарныеВзысканияСотрудников`, синоним «Дисциплинарные взыскания сотрудников».
- `бит_ШтрафыПДД`, синоним «Штрафы ПДД».

### Роли

Ограничение по подразделению не включать. Роли назначает человек.

`бит_КадровикВзыскания`, синоним «Кадровик (дисциплинарные взыскания)»: чтение и изменение регистра `бит_ВзысканияСотрудников`, чтение и изменение справочника `бит_ВидыВзысканий` (чтобы добавлять свои виды), использование отчёта `бит_ДисциплинарныеВзысканияСотрудников`. Права на штрафы не давать. Права на `НаградыФизическихЛиц` не добавлять: они уже есть у кадровика.

`бит_УчетШтрафовПДД`, синоним «Учет штрафов ПДД»: чтение и изменение регистра `бит_ШтрафыПДД`, использование отчёта `бит_ШтрафыПДД`. Права на взыскания, виды взысканий, награды, данные физических лиц и зарплату не давать. Чтение `Справочник.Сотрудники` не расширять: оно уже есть у этих пользователей через роль табеля.

## Что делает агент

Работать только в расширении `бит_Доработки`.

### Награды

Гиперссылку «Награды» на карточку сотрудника не добавлять. Отдельную форму `бит_Награды` не создавать. Награды редактируются только типовой таблицей на форме `ТрудоваяДеятельность`. Эту таблицу не менять и не удалять.

### Взыскания

Гиперссылку «Взыскания» на карточку сотрудника не добавлять. Отдельную форму `бит_Взыскания` не создавать. Взыскания редактируются только на форме `ТрудоваяДеятельность`.

На форму `ТрудоваяДеятельность` ниже типовой таблицы «Награды», в группе «Дисциплинарные взыскания», добавить редактируемую таблицу. Колонки: вид, дата, номер приказа, дата приказа, комментарий, расчётный статус. Вид выбирается из справочника `бит_ВидыВзысканий`. `НомерПоПорядку` на форме не показывать и заполнять при добавлении строки. Отбор: сотрудник принадлежит текущему физическому лицу. Новая строка получает сотрудника открытой формы и следующий `НомерПоПорядку` внутри этого сотрудника.

Статус взыскания в регистре не хранить и регламентное задание не создавать. «Действует», пока от даты приказа не прошёл год. Если дата приказа пустая, считать от даты взыскания. Иначе статус «Снято». Строку со статусом «Снято» зачёркивать на таблице формы «Трудовая деятельность». Запись не удалять.

### Штрафы

На формах списка и записи `бит_ШтрафыПДД` у поля `Сотрудник` выключить кнопку открытия. Выбор из списка оставить. Журнал штрафов — это форма списка регистра. Отдельный документ не создавать.

### Отчёты

- `бит_ДисциплинарныеВзысканияСотрудников`: регистр `бит_ВзысканияСотрудников`, вариант называется как синоним регистра «Дисциплинарные взыскания», отбор периода по дате приказа, колонка статуса и зачёркивание снятых.
- `бит_ШтрафыПДД`: дата, сотрудник, пункт, нарушение, сумма и итог по сумме, отбор периода по дате штрафа.

Оба отчёта группировать как типовой «Награды сотрудников»: организация, внутри подразделение, внутри сотрудник, затем строки. Организация — организация места работы, не головная. Подразделение — подразделение, в котором числится сотрудник, без раскрытия вышестоящих. Должность в группировки и отборы не включать.

Организацию и подразделение в регистры не записывать. Брать их из кадровых данных сотрудника на дату отчёта. Дата отчёта — конец выбранного периода; если конец периода пустой, текущая дата сеанса. Дата взыскания и дата штрафа на место работы не влияют.

Уволенных на дату отчёта не показывать: дата увольнения пустая или не раньше даты отчёта. Отборы по организации (равно) и подразделению (в иерархии) добавить выключенными, как в отчёте по наградам. Отбор по сотруднику оставить выключенным.

В отчёте по штрафам сумма складывается по сотруднику, подразделению и организации.

В панель разделов выносятся журнал и отчёт по штрафам: регистр и отчёт `бит_ШтрафыПДД` добавлены в подсистему «Табельщик» (`юцТабельщик`). Команды видны при праве просмотра регистра и отчёта, отдельных условий видимости нет. Остальные журналы и отчёты в панель разделов не выносить. Награды и взыскания открываются только на форме «Трудовая деятельность». Карточку сотрудника ссылками «Награды» и «Взыскания» не дополнять. Журнал штрафов открывается формой списка `бит_ШтрафыПДД`. Отчёт `бит_ДисциплинарныеВзысканияСотрудников` включён в подсистему `Кадры.ДисциплинарныеВзыскания`, подключён к панели отчётов через `ПодключаемыеОтчетыИОбработки` и модуль менеджера, и открывается в кадровых отчётах в группе «Дисциплинарные взыскания».

### Комментарии в коде

Любую вставку и замену кода обрамлять так:

```bsl
// +++ 1 бит Балицкий В.В. 11.20.2026
// здесь старый код
здесь код
// --- 1 бит Балицкий В.В. 11.20.2026
```

Строку «здесь старый код» писать только там, где заменён существующий код. В новом модуле её не оставлять.
